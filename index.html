Features

Your prompts, your selection, your AI account, all connected from any web page.

Choose what to send

Pick Highlighted Text, Page Content, Page Url or Page Title as the source for your prompt.

Seven AI assistants

Open your prompt in the assistant you prefer.

  • Grok
  • Gemini
  • Perplexity
  • Copilot
  • Qwen

Your own prompt library

Save and manage prompts, and add {{SELECTED_TEXT}} wherever the selected text should go. Edit a prompt before you send it, or type a new one on the spot.

Conversations that continue

The extension remembers the AI tab it connected to, so the next prompt continues the same conversation instead of starting a new one. Use several AIs at once; each AI tab is remembered separately.

How it works

Four steps, no copy-and-paste cleanup.

  1. Open the extension

    Right-click and choose Page to Prompt, or press Cmd + Shift + P. You can change the shortcut at chrome://extensions/shortcuts.

  2. Choose a source and an AI

    Select Highlighted Text, Page Content, Page Url or Page Title, then pick Claude, ChatGPT, Grok, Gemini, Perplexity, Copilot or Qwen.

  3. Pick a prompt

    Click a saved prompt to open the AI right away. Click the edit button next to it to load it into the input box and adjust it first, or write a new prompt there.

  4. Keep the conversation going

    Choose another prompt later and it continues in the same AI tab you already opened.
